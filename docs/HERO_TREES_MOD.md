# Деревья навыков, созданные модом

Сгенерировано `tools/Dump/HeroTreesDump.cs` из кода мода (`HeroTreeDesign.cs` - библиотека эффектов, `HeroTreeSpecs.cs` - состав каждого дерева). Значения - ровно то, что регистрирует игра.

Устройство: у каждого героя три дерева (партия, раса, класс), диктатор вместо классового получает дерево фракции. Деревья написаны отдельно для адмирала, губернатора, сенатора и диктатора. 4 ступени: три ступени одиночных навыков и вершина (один уровень, несколько эффектов сразу). Эффект не повторяется внутри дерева. Порог ступени (очки навыков): A/G 0/4/8/12; сенатор 0/2/4/6; диктатор 0/6/12/18.
